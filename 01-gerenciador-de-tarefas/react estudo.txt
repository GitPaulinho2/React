--Componentes--

no react, dividimos a aplicação em pequenos componentes. Vários componentes, quando combinamos, formam grandes estruturas. Dá para pensar nessas estruturas como se fossem peças de lego. è usado JSX para escrevê-los.

-- JSX (jéiesiequis) --

JSX é como um html, só que dentro do código javascript. É a principal maneira de escrever html com react. Podemos interpolar variáveis, inserindo ela entre chaves "{}". Também é possível executar funções em JSX e inserir valores em atributos de tags.

-- React Pratica -- 

Conseguimos usar elementos do javascript em um código html por meio do JSX. Nesse exemplo, ele está retornando a mensagem do elemento "message" dentro de uma div (não é possível retornar mais de um elemento, por exemplo, duas divs)

function App (){
  const message = "Ola mundo";
  return (
  <div>
    <h1>{message}</h1>
  </div>
    
  )
}

export default App;

State(Estado): state é uma variável que muda no react, ela faz com que o componente seja renderizado novamente, ou seja, executa a função novamente e atualiza a interface. Neste exemplo, transformamos a antiga constante "message", que apenas passava o valor que iria aparecer na tela, para um state, se tornando o valor do state. O "setMessage" será a função que irá alterar o valor da mensagem modificada após apertar o botão.

import { useState } from "react";

function App (){
  const [message, setMessage] = useState("Olá mundo")
  // State (Estado)
  return (
  <div>
    <h1>{message}</h1>
    <button onClick={function()  {
      setMessage("Ola react tocado")
    }}
    
    >Mudar mensagem
    
    </button>
  </div>
    
  )
}

export default App;
